convsearch settings

Server address

The address of your local convsearch server. It must stay on 127.0.0.1 or localhost — the extension only has permission to reach the loopback interface, so your conversations never leave this machine.

Live capture

When capture is on, conversations you open on chatgpt.com are saved to your local workspace as you read them, so they become searchable. Turn it off to browse without recording anything new; conversations already captured are kept either way.

Keyboard shortcut

Ctrl+Shift+K (⌘+Shift+K on macOS) opens convsearch from any tab. Chrome ignores the suggested chord if another extension already claimed it, so if nothing happens, set your own at chrome://extensions/shortcuts. Inside the popup, press Ctrl+/ for the full list of keys.
