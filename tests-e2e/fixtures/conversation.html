__TITLE__ Some other conversation

I want to search my old ChatGPT conversations offline. What retrieval architecture should a local conversation search tool use?

Use hybrid retrieval: a BM25 lexical index over passages plus dense embeddings, fused with reciprocal rank fusion. Segment each conversation into passages first so a long thread does not collapse into one vector.

How do I keep the index fresh without blocking the capture request?

Mark the vector index stale on write and rebuild it out of band. Embedding inline would block the capture POST for seconds.
